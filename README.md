# CSC205S26-project-manager
	
	A desktop application that helps to manage projects by allowing the user to input various tasks, organized by user set tags.

## Installation

	Copy the clone URL from the github page. In eclipse, select import under files. Then, select ‘projects from git’ under the git folder. Now, select the ‘clone URL’ option. Paste the clone URL into the URL field and select next. Continue to follow the steps as given within eclipse. Start application by running ‘MainApp’ class.
